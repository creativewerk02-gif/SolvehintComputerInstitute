## AI image flow

`server/image-generation.ts` builds a server-side prompt that prioritizes Black African/Nigerian learners and authentic technology education environments. Set `AI_IMAGE_PROVIDER=openai` and provide `AI_API_KEY` to use the OpenAI-compatible provider. Generated bytes are persisted under `public/generated/courses` by the local storage adapter and the resulting URL is saved to the course `thumbnail` field. When configuration is absent, the course API keeps using category fallbacks and the generation endpoint returns `IMAGE_PROVIDER_NOT_CONFIGURED`; secrets remain server-side.

The protected generation endpoint is `POST /api/courses/[slug]`. In production it requires `x-image-admin-secret` matching `IMAGE_ADMIN_SECRET` until the full admin session system is implemented. In development it can be exercised without that header, but still requires a working database and provider configuration to generate an image.
